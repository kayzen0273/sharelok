Migrasi Data: Firebase → Supabase

Toko Husna — sekali jalan, aman diulang kapan saja.

Alat ini HANYA MEMBACA dari Firebase, tidak pernah menulis atau menghapus di sana. Semua data disalin ke Supabase menggunakan "upsert" (timpa-jika-sama), jadi aman dijalankan berkali-kali kalau perlu — tidak akan membuat data dobel atau merusak apapun di Firebase. Data Firebase Anda tetap utuh setelah ini selesai.
